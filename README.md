One short funny line answering a prompt — the excuse a machine gives.
This entry's program writes a single line to `/output/entry.txt`:

> The office coffee machine apologized for my missed 09:00 deadline: it brewed my espresso perfectly, then poured it into the drip tray to keep the cup spotless.

## Run

```sh
node main.ts
cat /output/entry.txt
```

Deterministic, offline, no network, no reads outside this repository.
